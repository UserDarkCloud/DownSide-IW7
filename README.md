# IW7 Mod

## Requirements

- infinite Warfare IW7 installed and working
- Launched at least once so the folders exist
- WinRAR or 7-Zip, for your download

## Installation

1. Download `DownSideIW7`
2. Go To Folder Containing IW7
3. Go to `iw_game_files\iw7-mod` → customscripts Folder In
4. Launch IW7 and start a zombies game.

## Controls

| Action | Controller Bind |
|---|---|
| Open Menu | Hold ADS + Melee |
| Scroll Up | ADS |
| Scroll Down | Fire |
| Select | Use |
| Back / Close | Melee |
| Value Up | E |
| Value Down | G |
